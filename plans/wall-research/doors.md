# The doors that refuse a seat's call on the principal's words or on a record's fact

Task E of the wall research. Written 2026-10-15 by an Opus agent of session dae006d1. Meta workflow: the build session reads the rota workflow's code and records. Line numbers are at the checkout of 2026-10-15, commit 3941ba89.

A door here is code that raises a refusal on a seat's tool call and says why. The column "Test" says what the door matches:

- **phrase**: a fixed list of words, cues or shapes, matched on text that the principal or a seat wrote.
- **fact**: a fact of a record, for example a row, a file, an index entry or a test result.

The column "Count" quotes the measure that the door's frame closed on, or the last night count. The column "Held" says whether a later night shows the door's sign again: yes, no or unknown. The code holds about 335 `raise ValueError(` sites in `rota/roles`, `rota/core` and `rota/llm` (observed: grep, 2026-10-15). This table lists the doors that a frame names, and not every raise.
