# F6 probe: the criterion of a test

**Verdict: no disagreement on nights 170 and 171, F6 needs no helper.**

Disagreement count on the criterion id: 0 on night 170, 0 on night 171.
Every reader that maps a test to its criterion gives the same answer for all
85 test rows (48 on night 170, 37 on night 171). Two other kinds of
difference exist. Both are by design, and neither gives two criterion ids
for one test (see "Differences that are not F6").

Scripts: `map.py` (ast map), `data.py` (register shape), `probe.py` (the
rules), `scan.py` (search for retired rows). Output: `probe_out_170_171.json`,
`probe_out_165_164.json`. All in this folder. Run with `python -I`. The
script puts `D:/repos/rota` on `sys.path` itself, because `-I` ignores
`PYTHONPATH`.

## 5. Differences that are not F6

1. **Night 170, own-or-project, 7 tests.** `inh_59208be9`, `inh_d61ae3f4`,
   `inh_423b2511`, `inh_a2fbaf78`, `inh_1f091edf`, `inh_535bd3f3`,
   `inh_cccd7e47` in `b_3`. Each is the inherited copy of a merged Tester
   test of `b_1` or `b_2`, with the same path and the same body. Every
   reader gives criterion None. `harness._own` alone calls the copy "own",
   by path, to keep the Tester's warning filter (frame 207). `park_reds`
   calls a red copy "project". No copy ran red in `b_3`, so the night shows
   no effect.
2. **Retired criterion.** R1, R2 and R7 return a retired criterion. So
   `ruled_criteria`, the relay in `stage` and `_line_legend` would carry a
   retired criterion if a ruling named a test of one. No night shows that.

## 6. Reading

The 46 readers give one answer for the criterion of a test on nights 170
and 171. The only split is the retired filter, which frame 306 put in
`live_tests` on purpose, and which no night shows reaching a relay. A helper
`criterion_of(conn, ref)` would fold R1 to R7 into one call, but it fixes no
observed fault. If a later night shows a retired criterion in a relay, the
fix is `live_tests` in R2's three relay readers, not a new helper.

The 7 inherited copies on night 170 point at a different question: a merged
Tester test loses its criterion link when the next batch inherits it. Every
reader agrees on that answer, so it is not F6.
