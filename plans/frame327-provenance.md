The scope is wider than `refs`: 106 parameters in `api.py` with a list annotation, and every `msg.*` op's `refs`, advertise a string to a native seat (observed: a count over `api.py` signatures). The door itself works as its design of 2026-08-14 meant, but its text never showed a correct form, in text mode or native mode (observed: f73a7c01, the text unchanged since). In text mode no seat sent a JSON string list in this register: all 13 runs with that refusal are the native trial of 2026-10-25 15:20 to 15:34, stamped `text` by a known fault (observed: `case_runs`).
