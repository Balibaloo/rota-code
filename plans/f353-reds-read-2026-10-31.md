## Wall 1: a seat path in an exclude does not go through the one path reader

The fact: F11 of the rootfix audit (rule C76) says every path half of a grain goes through `_grain_path` (`rota/core/worktrees.py` `grain_path`). The reader folds a backslash, a space and the `./` and `/` prefixes. `_excluded_paths` in `rota/roles/api.py` (line 11676) takes the seat's raw text and splits it with `path.partition("::")`. A seat path like `./src/utils.py` or `src\utils.py` matches no prediction path, so the exclude is refused. 12c2f5f5 (frame 345 pass 7c) added the split one day after F11 landed, and the F11 list did not get the site.

Reach: 1 site. The test finds no other stray split in the package.

Price: under 2 cycles. Fold the path half through `_grain_path` before the match, then the test passes with no change to `ALLOWED`.

## Wall 2: the hole filler rewrites angle tokens that are not holes

The fact: `fixtures.fill` replaces every `<name>` in a case file with an unguessable id, before the YAML parse. Its design says holes are declared. Real text in two cases carries angle tokens that are not holes, so the model reads a changed text:

- `l1_tester.yaml:1396`: a click docstring says ``<stdout>``, and the run shows an id there.
- `l1_answers.yaml:148`: a traceback says `option.<locals>.decorator()`, and the run shows an id there.
- `l1_liaison2.yaml:356`: a comment says `guess:<item>`. The fill does no harm here.

The test catches `<stdout>` and `<item>` only because the same words appear bare. It misses `<locals>`. It also flags false hits: the prose word "item" in 9 comments, and the L3R case ids such as `L3R-n174-m53-m55` with two comments in `l3_rulings.yaml`. Those are not foreign keys.

Reach: 3 non-hole tokens in 3 case files, 2 of them in text a model reads. The false hits: 9 lines in `l1_liaison2.yaml`, 19 in `l1_tester.yaml`, about 60 case-id and comment lines in `l3_rulings.yaml`.

Price: under 2 cycles. Make `fill` replace only a name that the case declares as a hole, or escape the three tokens in the case text. Then narrow the test to skip comment lines and `- id:` lines.
