### intent
In this project, an intent is a template for generating new notes. It is declared in the `src/intents/index.ts` file and used throughout the codebase to create new notes with specific content.

### template
In this project, a template is a predefined structure or pattern for generating new notes, typically stored in files and used as a starting point for user input.

### prompt
In this project, a prompt is ... a thing in the code that represents user input or a value to be filled in, used for creating notes with templates or intents.

### variable
In this project, a variable is a named value that can be used in templates or notes, declared in frontmatter or defined by the plugin's settings.

### variable_type
In this project, a variable type is ... a data structure that defines the format and constraints of a value in code. It is written down in various files such as `src/variables/providers/index.ts` and used throughout the plugin to validate and process user input.

### provider
In this project, a provider is ... a module that exports functions for parsing and getting variables, used in various parts of the code to handle variable-related logic.

### frontmatter
In this project, a frontmatter is ... metadata stored at the top of a note file.

### global_intent
In this project, a global intent is ... an intent stored in a specific note designated by the plugin's settings.

### selection
In this project, a selection is ... an EditorSelection object representing the currently selected text in the active editor.

### filter_set
In this project, a filter set is ... a collection of rules or criteria used to narrow down the list of notes shown in Obsidian, defined by the user through settings and stored as a string.
