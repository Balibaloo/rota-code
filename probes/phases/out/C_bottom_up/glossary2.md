### intent
In this project, an intent is a type that represents a specific action or task in the program, defined by its properties and behavior. It is declared in `src/intents/index.ts` and used throughout the codebase to manage intents in the Obsidian plugin.

### template
In this project, a template is a predefined structure for generating content in the Obsidian app. It is defined in various files such as `src/templates/index.ts` and used throughout the codebase to create templates that can be applied to notes.

### prompt
In this project, a prompt is ... a thing in the code that appears as a modal window to the user for inputting values or selecting templates. It is declared in `src/variables/suggest.ts` and used throughout various files, including `README.md`, `src/intents/frontmatter.ts`, and `manifest.json`.

### variable
In this project, a variable is a value that can be used in a template to customize its behavior or appearance. It is declared in the `src/variables/index.ts` file and used throughout the codebase, particularly in the `src/intents/frontmatter.ts`, `src/intents/index.ts`, and `src/main.ts` files.

### variable_type
In this project, a variable type is ... TemplateVariableType. It is written down in the `src/variables/providers/index.ts` file and used throughout various parts of the code to define different types of template variables.

### provider
In this project, a provider is ... a function or object that supplies data to the program, specifically used in the `src/variables/providers` directory for parsing and validating variables such as text, numbers, natural dates, folders, and notes.

### frontmatter
In this project, a frontmatter is metadata stored at the top of a note file.

### global_intent
In this project, a global intent is ... an Intent object that has been made available globally.

### selection
In this project, a selection is an EditorSelection object that represents the currently selected text in the editor. It is used to determine what text should be used when creating new notes or populating prompts.

### filter_set
In this project, a filter set is ... a collection of note filters used to narrow down the list of notes shown.
