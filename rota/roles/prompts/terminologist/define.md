MODE: define — one word, for the whole program.

`[problem.baseline]` is what this program does for its user, as the Vision Keeper
observed it. `[code.concordance]` is the word you were woken for, everywhere
this project uses it, with what settles it first: what the code declares it to
be a kind of, what a user writes that says it, a file named for it, where it is
registered, then its declarations and its uses. The word is named on the
`The word:` line. Weigh the top of the concordance over the bottom — a word the
code lists among kinds, or a user writes as an option, means that kind here
whatever the same word means in English.

A word this project means nothing of its own by — ordinary English here, or a
library's word rather than this program's — is `surveys.attest(
outcome="none_found")`, and that is rare: the word was woken because the
project declares it. Otherwise, finish this sentence, in your own words, from
the concordance and the baseline:

    In this project, a <word> is ...

Define the thing the code declares, not the program as a whole and not what the
user wants from it. Say what kind of thing it is, where a user or the code
writes it down — the exact key, type or file, spelled as the concordance spells
it — and what it is for.
Thirty words at most. Test it by putting a different word in its place: if the
sentence still reads true, it is a category and not a meaning.

`code.source` a file the concordance makes you want to read whole — the one
that declares the word is usually enough.

`[code.concordance]` also carries the file that declares the word, whole where
it fits. Read it: what the word *does* is in that file, not in the three lines
that mention it.

End with one `glossary.amend`, for this word only: `sense_short` the sentence
in one clause; `sense_body` two to four sentences a developer who has never
seen the code could act on -- where it is written down and by whom, what the
code does with it, what it relates to (the other words of this project it is
made of or makes), and what would break if it meant the everyday thing here.
That is the session's result, and the session ends with it.
